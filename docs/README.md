# Documentation

This directory contains development and technical documentation for the OpenSubtitles Uploader PRO project.

## Files

### `plans/`
The Phase 2 fork & REST migration plans — start at [`plans/00-README.md`](plans/00-README.md),
which carries the reading order, the status board, and a **Current state**
section listing what is shipped and what is still open. Read this first if you
are picking the project back up.

### `superpowers/`
Specs and implementation plans written during feature work
(`superpowers/specs/` for designs, `superpowers/plans/` for the task-by-task
plans derived from them).

### `CLAUDE.md`
Comprehensive development guide and project instructions for Claude Code AI assistance. Contains:
- Project overview and architecture
- Development commands and workflows
- Version management procedures
- Technical implementation details
- Troubleshooting guides
- Feature documentation

### `CACHING_OPTIMIZATION.md`
Technical documentation about the application's caching strategies and optimizations:
- Cache implementation details
- Performance optimization techniques
- Caching strategies for different components
- Cache invalidation policies

## For Developers

- **CLAUDE.md** is the primary reference for development workflows and project setup
- **CACHING_OPTIMIZATION.md** provides insights into performance optimizations
- Additional documentation may be added as the project evolves

## Usage

These documents are primarily intended for:
- Contributors and developers working on the project
- AI assistants (like Claude Code) providing development support
- Performance optimization analysis
- Architecture decision documentation
