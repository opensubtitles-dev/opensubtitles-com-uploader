## v2.0.0 - v2.0.0

*Released: 8/18/2026*

fix: declare the reqwest stream feature the updater download needs

src-tauri/src/main.rs calls response.bytes_stream() for download progress,
which requires reqwest's "stream" feature. tauri-plugin-http offers it but has
never enabled it by default — not in 2.5.1, not in 2.5.9. It compiled only
through accidental feature unification: another crate in the old graph turned
reqwest/stream on, and Cargo unified it across the build.

Updating the dependency graph removed that crate and the accident with it,
breaking the compile. Declaring the feature explicitly fixes it for good and is
correct regardless of which Tauri version this lands on.

Also picks up the regenerated ACL schemas, which reflect the new plugin versions.
